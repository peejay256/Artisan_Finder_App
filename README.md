# Artisan_Finder_App

This is my Capstone project for the NextGen Cohort with 3MTT. Finding trustworthy artisans and skilled workers to help with tasks is proving more difficult; so this is a Minimum Viable Product of an app built to solve that problem. Bridging the gap between customers and artisans is how this is solved.

I created this repo while working on the site map and wireframes for the pages of the app. Soon, I will get to work creating the website. I intend using React + Vite to create the frontend of the website. Also, this is a learning process for me; the difference between knowing the definition of things and actually putting those things to actual use. I hope to work on this everyday and regularly commit even as I continue working.

I chose to call it Find'em because intuitively, that name came to me while brainstorming and because I want to learn. I have ChatGPT strictly as a learning guide; and I am checking and learning with some youtube videos. I occasionally go back to the recordings of the classes with Mr Julius Adebowale.

Basically, using the app, a customer should be able to:

1. Open Find'em
2. Search for an artisan
3. See matching artisans
4. View an artisan's profile
5. Submit a booking request
